# Локальный файловый агент

Учебный агент работает с арифметикой и файлами в выбранной рабочей папке. В проект входят инструменты просмотра, точечной замены, создания файлов и вложенных каталогов, а также история диалогов между запусками.

## Установка и запуск

Нужен Python 3.11 или новее. В PowerShell из папки проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
Copy-Item .env.example .env
```

Добавьте свой `DEEPSEEK_API_KEY` в `.env`, затем запустите агент:

```powershell
.\.venv\Scripts\sberagent.exe --help
.\.venv\Scripts\sberagent.exe "Сложи 18 и 24"
```

В VS Code выберите конфигурацию запуска «Локальный агент» и нажмите F5. В открывшемся терминале введите запрос после подсказки `Ваш запрос:`. Такой же интерактивный запуск доступен командой `python run.py`.

Перед запуском перейдите в папку, с которой агент должен работать. Текущая папка терминала становится workspace:

```powershell
Set-Location .\games
..\.venv\Scripts\sberagent.exe "Перечисли файлы и папки"
```

## Что сделано в ДЗ

- Добавлены арифметические инструменты: сложение, вычитание, умножение и деление.
- `read_file` и `list_files` позволяют читать файлы и просматривать содержимое workspace.
- `replace_in_file` меняет ровно одно совпадение, показывает diff и не меняет файл при неоднозначном результате.
- `create_file` создаёт UTF-8 файл, но отказывает, если такой файл уже существует.
- `create_directory` создаёт вложенные каталоги; при существующем каталоге возвращает понятный статус.
- История диалога сохраняется между запусками отдельно для каждой рабочей папки и ограничивается настройкой `HISTORY_TURNS`.
- Проверки безопасности ограничивают файловые операции workspace, блокируют `.env`, `.agent-memory`, выход наружу и небезопасные ссылки. Для операций записи действует таймаут.

## Память и настройки

История хранится отдельно для каждого workspace в SQLite вне доступной агенту файловой области. По умолчанию `HISTORY_TURNS=10` сохраняет десять пар вопрос–ответ; значение `0` отключает чтение и запись истории. Папка `.agent-memory` и секреты в `.env` исключены из Git.

Основные настройки находятся в `.env`: ключ `DEEPSEEK_API_KEY`, лимит шагов `AGENT_MAX_STEPS`, таймауты модели и инструментов, `AGENT_LOG_EVENTS` и `HISTORY_TURNS`. Их безопасный шаблон — [.env.example](.env.example).

## Игры

В `games/snake.html` — «Змейка» в аркадном оформлении с управлением клавишами и сенсорными кнопками. `games/bad-site.html` — витрина комнатных растений «Тихий сад» с избранным. Файлы можно открыть в браузере. `games/quest` содержит материалы квеста для упражнений с файлами.

Локальные unit-тесты запускаются командой:

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```
